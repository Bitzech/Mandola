Develop the complete Seller Dashboard for the Mandola Fashion Marketplace.

IMPORTANT:
Do NOT change the existing website design, color palette, typography, spacing, icons, buttons, header, footer, animations, border radius, shadows, or responsiveness. The Seller Dashboard must look like it is part of the existing Mandola website. Maintain the same premium women's fashion design language and UI components.

Authentication Flow:
- When a seller logs in using valid seller credentials (seller_email/seller_phone and password), automatically redirect to the Seller Dashboard.
- If the logged-in user's role is "seller", open the seller dashboard.
- Do not show customer or admin pages.

Layout:
- Keep the existing website header exactly the same.
- Keep the existing website footer exactly the same.
- Responsive for Desktop, Tablet, and Mobile.
- Modern dashboard layout with left sidebar and main content area.
- Use breadcrumb navigation on all pages.
