Develop the complete Admin Dashboard for the Mandola Fashion Marketplace.

IMPORTANT:
Do NOT change the existing website design, branding, typography, color palette, spacing, icons, buttons, shadows, border radius, animations, header, or footer. The Admin Dashboard must feel like a natural extension of the existing Mandola website. Maintain the same premium women's fashion design language and UI consistency.

Authentication Flow:
- When an admin logs in using valid admin credentials (admin_email/admin_phone and password), automatically redirect to the Admin Dashboard.
- If the logged-in user's role is "admin", display the Admin Dashboard.
- Do not show customer or seller pages.

--------------------------------------------------
LAYOUT
--------------------------------------------------

- Keep the existing website header exactly the same.
- Keep the existing footer exactly the same.
- Responsive for Desktop, Tablet and Mobile.
- Fixed left sidebar.
- Sticky top navigation bar.
- Modern dashboard layout with breadcrumb navigation.
- Light premium UI with elegant cards and clean spacing.
